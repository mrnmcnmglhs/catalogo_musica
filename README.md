# Catálogo Musical

Projeto de estudo fullstack para explorar artistas e álbuns.

## Tecnologias previstas

- Frontend: Next.js e TypeScript
- Backend: Python e FastAPI
- Banco de dados: PostgreSQL
- Ambiente do banco: Docker pelo WSL

## Primeira versão

- Cadastro de artistas e álbuns
- Álbuns vinculados a artistas
- Busca por nome e filtro por gênero musical
